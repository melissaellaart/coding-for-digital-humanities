# Coding for Digital Humanities: Workshop Notes

## Module II: Basic Computational Tools

In this module I learned how to work with **basic computational tools** that support a *digital humanities* workflow. I used the command line to move between folders and create files, and I opened a new note directly in **Visual Studio Code** by typing `code [note name].md`. I learned that *Markdown* is a simple markup language that formats plain text and converts it into HTML, which is what makes this page possible.

What I practised:

- Navigating folders and creating files from the **command line**
- Writing a note in **Markdown** using headings, *italics*, **bold** text and lists
- Tracking my work with **Git** and pushing it to a **GitHub** repository
- Publishing the note as a static page with **GitHub Pages**

I plan to use these skills to keep *version-controlled* research notes and to build a simple personal page or eCV.
